ZARIS MACHINE A COUDRE - fichiers du site

index.html    Site boutique pour les clients (catalogue, reservation, commande WhatsApp)
gestion.html  Page de gestion (devis, factures, BC, BL). Connexion : ndey
logo.jpg      Logo ZARIS

Reglages (numero WhatsApp, livraison...) : ouvrir index.html dans un editeur de texte
et modifier le bloc "const CFG" au debut du script.

Notes :
- Les fichiers fonctionnent en les ouvrant dans un navigateur, ou apres mise en ligne sur un hebergeur.
- Hors de Claude, la base de donnees partagee n'existe pas : gestion.html enregistre les documents
  dans le navigateur de l'appareil utilise uniquement.
- La connexion de gestion.html cache la page aux visiteurs, mais ne remplace pas une vraie securite serveur.
